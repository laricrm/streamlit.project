# Streamlit Project

Este projeto foi criado para praticar o uso de Python, Streamlit e versionamento com GitHub.

##  Funcionalidades

- Aplicação simples com Streamlit
- Scripts em Python
- Organização de projeto
- Controle de versão com Git

## Como executar

Clone o repositório:

git clone https://github.com/laricrm/streamlit.project.git

Acesse a pasta:

cd streamlit.project

Instale as dependências:

pip install -r requirements.txt

Execute o projeto:

streamlit run app.py

##  Tecnologias utilizadas

- Python
- Streamlit
